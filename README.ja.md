# Scrollim

Neovim の縦スクロール操作 **4つだけ**（`gg` / `Shift+G` / `Ctrl+u` / `Ctrl+d`）を有効にする、ミニマルな Chrome 拡張機能です。

[English README](README.md)

## コンセプト

Vimium のような多機能拡張は便利ですが、`j` / `k` / `f` / `/` などが GitHub・Gmail・Notion・X などの Web アプリ標準ショートカットと干渉することがあります。**Scrollim** は「縦移動の4操作だけ」に絞ることで、Web アプリの操作性を邪魔せず Neovim ライクな高速スクロールを実現します。

## キーバインド

| ショートカット | 動作 |
| --- | --- |
| `g` `g` | ページの先頭へ移動 |
| `Shift` + `G` | ページの末尾へ移動 |
| `Ctrl` + `u` | 半ページ上へスクロール |
| `Ctrl` + `d` | 半ページ下へスクロール |

## 主な機能

- **4操作のみに厳選**: 他のキーは一切奪いません。
- **入力中は自動で無効化**: `<input>` / `<textarea>` / `<select>` / `contenteditable` / Shadow DOM 内の入力欄、および日本語 IME 変換中は反応しません。
- **SPA の内部スクロールにも対応**: `body` ではなく内部コンテナがスクロールする Web アプリでも、フォーカス・クリック位置やメイン領域を自動判定してスクロールします。
- **スムーズ / 即時スクロール切り替え**: 連打・長押しでも引っかかりにくいアニメーション（`prefers-reduced-motion` 対応）と即時スクロールをポップアップから切り替え可能。半ページの移動量（25%〜80%）も調整できます。
- **ホスト名ごとの一時停止**: ツールバーのポップアップから、現在のホスト名単位（完全一致：`example.com` と `www.example.com` は別扱い）でワンクリック無効化できます。
- **プライバシー重視・ゼロ依存**: Manifest V3、最小限の権限（`storage` / `activeTab`）、外部通信・トラッキングなし。詳細は [PRIVACY.md](PRIVACY.md) をご覧ください。

## インストール（ローカル読み込み）

1. このリポジトリをクローンまたはダウンロードします。
2. Chrome で `chrome://extensions` を開きます。
3. 右上の **デベロッパー モード** をオンにします。
4. **パッケージ化されていない拡張機能を読み込む** をクリックし、このリポジトリのルートフォルダを選択します。

## 開発・テスト・ストア用パッケージ作成

ビルド不要・外部パッケージ依存ゼロで動作します。

```bash
# ユニットテストの実行（Node.js 18以上）
npm test

# Chrome Web Store 提出用 ZIP の生成（dist/scrollim-v<version>.zip）
npm run zip

# アイコン PNG の再生成（Python 3 標準ライブラリのみ）
npm run icons
```

## 注意事項

- Chrome の仕様により、`chrome://*` ページおよび Chrome Web Store 上ではコンテンツスクリプトは動作しません。
- スクロール不可の埋め込み iframe にキーボードフォーカスがある場合、外側の親ページへ跨いでスクロールは行いません。
